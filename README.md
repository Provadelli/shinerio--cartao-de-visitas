## Sobre o projeto

Este projeto consiste no desenvolvimento de um **Cartão de Visitas Digital para a Shine Rio**, criado com o objetivo de apresentar as informações da empresa de forma moderna, organizada e acessível.

O projeto foi desenvolvido por **Pedro Lucas** como uma solução digital personalizada para a Shine Rio, reunindo informações e canais de contato em uma única página.

A proposta é oferecer uma alternativa moderna ao cartão de visitas tradicional, permitindo que as informações da empresa sejam acessadas e compartilhadas facilmente pela internet.

---

## Sobre a Shine Rio

A **Shine Rio** é uma empresa especializada em **terceirização e locação de mão de obra**, oferecendo soluções para empresas que necessitam de profissionais e serviços especializados.

O cartão digital foi desenvolvido para funcionar como um ponto central de contato, facilitando o acesso às principais informações e canais de comunicação da empresa.

---

## Objetivo

O principal objetivo do projeto foi desenvolver uma apresentação digital que fosse:

* Moderna
* Profissional
* Responsiva
* Intuitiva
* Adaptada para dispositivos móveis
* Rápida e fácil de acessar
* Alinhada à identidade visual da Shine Rio

## Estrutura do projeto

```text
shinerio--cartao-de-visitas/
│
├── assets/
│   └── arquivos visuais do projeto
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Arquivo responsável pela estrutura principal do cartão de visitas e organização dos elementos apresentados ao usuário.

### `style.css`

Arquivo responsável pela identidade visual e apresentação da interface, incluindo:

* Cores
* Tipografia
* Layout
* Espaçamentos
* Botões
* Responsividade
* Efeitos visuais

### `script.js`

Arquivo responsável pelas funcionalidades e interações desenvolvidas em JavaScript.

### `assets/`

Diretório destinado aos recursos visuais utilizados no projeto, como imagens, logotipo e outros elementos gráficos.

## Responsividade

O projeto foi desenvolvido com foco na experiência em dispositivos móveis, considerando que o cartão de visitas será principalmente acessado através de smartphones.

A interface também se adapta a diferentes tamanhos de tela, proporcionando uma experiência consistente em celulares, tablets e computadores.

---

## Conceito

A proposta do projeto é transformar o cartão de visitas tradicional em uma experiência digital.

Em vez de apresentar apenas informações básicas de contato, a página funciona como um ponto central de acesso às informações e canais da Shine Rio.

Dessa forma, o cartão pode ser compartilhado através de um único link e acessado de qualquer dispositivo conectado à internet.

## Como executar o projeto localmente

Clone o repositório:

```bash
git clone https://github.com/Provadelli/shinerio--cartao-de-visitas.git
```

Entre na pasta do projeto:

```bash
cd shinerio--cartao-de-visitas
```

O projeto utiliza HTML, CSS e JavaScript, portanto não possui dependências externas que precisem ser instaladas.

Para executar, basta abrir o arquivo `index.html` em um navegador.
